# Распознавание текста с фотографий

Кладёте фото в папку, программа сама делает из них текстовые файлы `.txt`.
Распознаёт русский и английский текст. Работает без интернета (интернет нужен только при установке).

## Установка (один раз)

1. Скопируйте папку `ocr-tool` куда удобно, например в `C:\OCR` или в «Документы».
2. Дважды щёлкните **`install.bat`**.
   - Если Python не установлен, программа установит его сама.
   - Установка займёт 5–15 минут и скачает около 1 ГБ. Не закрывайте окно.
3. Когда появится надпись «Готово!», на рабочем столе будут три ярлыка:
   - **Распознать текст с фото** запускает программу;
   - **Фото для распознавания** открывает папку, куда класть фото;
   - **Распознанный текст** открывает папку с готовыми `.txt`.

Если Windows покажет синее окно «Система Windows защитила ваш компьютер»,
нажмите «Подробнее», затем «Выполнить в любом случае».

## Как пользоваться

1. Запустите ярлык **«Распознать текст с фото»**. Откроется чёрное окно и папка «Фото».
2. Перетащите или скопируйте фотографии в папку **«Фото»**.
3. Через несколько секунд в папке **«Текст»** появится файл с тем же именем:
   `IMG_1234.jpg` превратится в `IMG_1234.txt`.
4. Пока окно открыто, программа обрабатывает каждое новое фото.
   Чтобы остановить её, закройте окно.

Уже распознанные фото повторно не обрабатываются. Чтобы распознать фото заново,
удалите его `.txt` из папки «Текст».

## Полезно знать

- Форматы: JPG, PNG, HEIC (iPhone), BMP, TIFF, WEBP.
- Одно фото обрабатывается от нескольких секунд до минуты, в зависимости от компьютера.
- Лучше всего распознаются ровные, резкие и хорошо освещённые снимки.
  Рукописный текст распознаётся плохо.
- Все сообщения программы сохраняются в файл `ocr.log`.
