# 🤖 Тендерный агент ЕИС

Автоматический сборщик тендеров с zakupki.gov.ru на Python + Selenium.
Ищет закупки по 44-ФЗ по ключевым словам, скачивает документацию и
загружает её на Google Диск (или оставляет на компьютере — переключается
при запуске).

## Структура проекта

```
parsergoszak/
├── main.py                  # Точка входа и параметры запуска
├── settings.toml            # ⚙️ Настройки: ключевые слова, куда качать и т.д.
├── settings.py              # Чтение settings.toml и параметров запуска
├── config.py                # Значения по умолчанию
├── requirements.txt
│
├── scraper/
│   ├── browser.py           # Selenium с антибот-настройками
│   ├── eis_parser.py        # Парсинг страниц поиска ЕИС
│   └── downloader.py        # Скачивание документов
│
├── storage/
│   ├── db.py                # SQLite: тендеры, документы, логи запусков
│   └── drive.py             # Загрузка на Google Диск
│
├── docs/                    # Скачанные документы (папка по номеру закупки)
└── logs/                    # Логи работы агента
```

## Установка (Windows)

Нужны Python 3.11+ и Google Chrome.

```powershell
cd C:\Panoptis\parsergoszak
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Для режима «Google Диск» нужен ещё файл `credentials.json` — см. раздел
[Google Диск](#google-диск) ниже. Для режима «локально» он не нужен.

## Настройки

Всё основное — в `settings.toml` (открывается Блокнотом, сохранять в UTF-8):

```toml
target = "drive"             # "drive" — на Google Диск, "local" — только на компьютер

keywords = [
    "поставка офисной бумаги",
    "поставка бумаги а4",
]

laws = ["44"]                # "44" и/или "223"
max_pages = 5                # страниц результатов на каждое слово
download_limit = 50          # закупок на скачивание за запуск
headless = true              # false — показывать окно браузера

drive_folder = "Panoptis — тендеры 44-ФЗ"
keep_local_copy = true       # false — удалять файлы с компьютера после загрузки
```

Полный список с пояснениями — в самом файле. Любой параметр можно
переопределить при запуске: **параметры запуска важнее settings.toml**.
Можно держать несколько файлов настроек и выбирать нужный через `--config`.

## Запуск

```powershell
# Всё по settings.toml: поиск + скачивание (+ загрузка на Диск, если target = "drive")
python main.py

# Куда качать — переключатель при запуске
python main.py --drive          # скачать и загрузить на Google Диск
python main.py --local          # скачать только на этот компьютер

# Свои ключевые слова вместо settings.toml (флаг -k можно повторять)
python main.py -k "картридж" -k "тонер для принтера"

# Другой файл настроек
python main.py --config бумага.toml

# Прочие параметры
python main.py --pages 3 --limit 20       # 3 страницы поиска, не больше 20 закупок
python main.py --laws 44 223              # оба закона
python main.py --docs-dir D:\tenders      # куда качает браузер
python main.py --drive-folder "Тендеры"   # другая папка на Диске
python main.py --no-keep-local            # удалять локальные файлы после загрузки
python main.py --show-browser             # смотреть браузер живьём

# Режимы
python main.py --no-download     # только поиск (без скачивания)
python main.py --only-download   # только скачать документы для уже найденных тендеров
python main.py --only-upload     # только догрузить на Диск уже скачанное (без браузера)
python main.py --drive-login     # войти в Google и проверить доступ (один раз)

python main.py --help            # все параметры
```

## Google Диск

Документы каждой закупки попадают в
`Мой диск / Panoptis — тендеры 44-ФЗ / <номер закупки> /`.
Папку скрипт создаёт сам при первом запуске; потом её можно переместить
в любое место Диска или переименовать в `settings.toml` (`drive_folder`).

Скрипт получает доступ **только к файлам, которые создал сам** (права
`drive.file`) — остальной Диск ему не виден.

### Первоначальная настройка (один раз, ~10 минут)

1. Открой [Google Cloud Console](https://console.cloud.google.com/) под
   своим Google-аккаунтом и создай проект (например, `Panoptis`).
2. Включи [Google Drive API](https://console.cloud.google.com/apis/library/drive.googleapis.com) → **Enable**.
3. Открой [Google Auth Platform](https://console.cloud.google.com/auth/overview) → **Get started**:
   название приложения любое (`Panoptis`), почта — своя,
   Audience — **External**.
4. В разделе **Audience** нажми **Publish app** (статус «In production»).
   Без этого вход в Google будет слетать каждые 7 дней. Проверка Google
   не нужна — скрипт просит только доступ к своим файлам.
5. В разделе [**Clients**](https://console.cloud.google.com/auth/clients) → **Create client** →
   тип **Desktop app** → **Create** → **Download JSON**.
   Сохрани файл как `credentials.json` рядом с `main.py`.
6. Запусти вход:
   ```powershell
   python main.py --drive-login
   ```
   Откроется браузер — выбери аккаунт и разреши доступ. Если Google
   покажет «Приложение не проверено» — «Дополнительно» → «Перейти».
   После этого рядом появится `token.json`, и дальше парсер работает
   без участия человека.

`credentials.json` и `token.json` — личные ключи доступа: не отправляй их
никому и не коммить в git (они в `.gitignore`).

### Как это работает

- Браузер качает файлы в `docs/<номер>/`, после каждой закупки папка
  сразу загружается на Диск. Последним загружается `_done.flag` — если он
  есть на Диске, значит все документы закупки уже там.
- Если интернет пропал или Google не ответил — файлы остаются на
  компьютере и догружаются в конце запуска или при следующем запуске
  (или вручную: `--only-upload`). Повторно одни и те же файлы не грузятся.
- Загруженная папка помечается файлом `_uploaded.flag`. При
  `keep_local_copy = false` локальная копия удаляется сразу после загрузки.

### Без Google Cloud

Если на компьютере стоит «Google Диск для компьютера», можно обойтись без
`credentials.json`: качать локально прямо в синхронизируемую папку.

```powershell
python main.py --local --docs-dir "G:\Мой диск\Panoptis"
```

## Что сохраняется

**SQLite база** (`storage/tenders.db`):
- `tenders` — метаданные закупок (номер, название, заказчик, цена, даты)
- `documents` — пути к скачанным файлам + тип документа
- `search_runs` — история запусков (когда, что искали, сколько нашли)

**Файлы** (`docs/<номер_закупки>/` и/или Google Диск):
- PDF, DOCX, XLSX и другие форматы документации
- Автоклассификация: ТЗ / проект_контракта / условия / прочее

## Следующий шаг — оркестрация с LLM

После накопления документов подключим локальную LLM (llama.cpp) для:
- Извлечения ключевых требований из ТЗ
- Оценки рисков
- Формирования дайджеста

## Важные нюансы ЕИС

- По умолчанию ищутся только закупки по 44-ФЗ (`laws = ["44"]`);
  223-ФЗ включается так: `laws = ["44", "223"]`
- 44-ФЗ и 223-ФЗ имеют разные структуры URL
- FTP-выгрузки закрыты с января 2025
- SOAP API требует ЭЦП юр.лица
- Сайт иногда лагает — в агенте есть ретраи и случайные паузы
